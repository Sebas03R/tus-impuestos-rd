# Conceptos de logo

Tres direcciones en blanco y negro para reemplazar la marca actual (cuadro amarillo con etiqueta):

- **A · Sobreprecímetro**: un medidor cuyo tramo de sobreprecio engorda; el pivote es el ojal de una etiqueta.
- **B · Pancarta**: una etiqueta de precio clavada en un palo, inclinada como una pancarta en alto.
- **C · La etiqueta que pregunta** (recomendado): una etiqueta de precio con el «¿» calado; el punto del signo hace de ojal. Une la pregunta de la portada («¿Por qué pagaron tanto?») con la etiqueta de precio y se lee bien a 16 px.

`concepts.png` resume los tres con tamaños reales de 64, 32 y 16 px. Los SVG son trazados (sin texto vivo); las letras salen de Big Shoulders Black (SIL Open Font License, permite su uso en logotipos). `construir.py` regenera los archivos (requiere `fonttools`).

Elegido: **C · La etiqueta que pregunta** (10 de noviembre de 2026). El kit final está en `../logo/` y la guía en `../README.md`.
